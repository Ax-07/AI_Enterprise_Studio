AI ENTERPRISE STUDIO — V0.1 / Fondation
=======================================
Windows, Python 3.10+ (bibliothèque standard uniquement). Pas de pip, pas de Docker ou n8n nécessaires à ce prototype. Les anciennes versions d'AI Collective Studio restent intactes. Port 8790, localhost uniquement.

1. Décompresser dans un nouveau dossier.
2. Double-cliquer Demarrer_Enterprise.bat. Si le navigateur ne s'ouvre pas : http://127.0.0.1:8790
3. Cliquer Simulation gratuite. Les cinq rapports sont pré-écrits et explicitement fictifs. Cela vérifie la chaîne, le journal SQLite et les décisions, sans IA ni connexion réseau.
4. Pour le cloud : arrêter (Ctrl+C), copier config.example.json sous le nom config.json, renseigner openai_api_key (ou variable OPENAI_API_KEY) en privé, puis relancer. La clé ne doit jamais être envoyée dans le chat, publiée sur GitHub ou partagée. Préférer une clé dédiée au projet. Brave est facultatif, renseigner brave_api_key uniquement si le compte et ses tarifs sont vérifiés. Sinon, ORION ne dispose d'aucune source réelle et doit l'indiquer.
5. Cliquer Lancer avec OpenAI et confirmer. 5 appels maximum par mission, 3 recherches Brave maximum par mission. Pas de relance automatique. Les réponses et coûts sont sauvegardés. Le mode cloud requiert des modèles accessibles à ton compte API. Modèles/prix de référence Standard au 24/11/2026 : gpt-6-luna 0.10/0.50 USD par million tokens entrée/sortie, gpt-6.1-terra 1/5, gpt-6.2-sol 2/10. Vérifier https://developers.openai.com/api/docs/pricing avant utilisation. Aucun outil OpenAI payant n'est activé.
6. Le budget OpenAI de 2 USD est cumulatif pour cette base SQLite, pas par mission. La réservation utilise une estimation prudente de l'entrée + sortie maximale. Si une réponse est interrompue ou son coût inconnu, la réservation reste comptabilisée. Coûts estimés bruts hors taxes, sans remise, pas de garantie contre un dépassement fournisseur. Le crédit déclaré de 15 USD n'est pas lu depuis OpenAI. Vérifier le tableau de bord de facturation et les limites fournisseur ; désactiver le rechargement automatique si souhaité. Brave : plafond cumulatif de 10 tentatives par défaut, vérifier son propre quota/coût. Aucun achat automatique. Les limites ne se réinitialisent pas chaque mois.
7. Arrêter une mission empêche le démarrage de nouvelles étapes après contrôle de l'état ; un appel déjà en cours peut encore être facturé. Un redémarrage marque les missions interrompues, aucune répétition automatique. Ne pas effacer la base pour récupérer artificiellement du budget ; rapprocher les réservations avec la facturation réelle.
8. Les demandes de ressources peuvent être acceptées pour étude ou refusées. Aucune autorisation ne déclenche de dépense ou action externe. Les recherches Brave affichent des extraits, pas des pages vérifiées.

Données : donnees/enterprise.sqlite3 ; sauvegarder le dossier quand le serveur est arrêté. Conserver config.json séparément en lieu sûr. Ne pas exposer le serveur sur Internet. Il n'est pas conçu pour plusieurs utilisateurs ni pour un PC partagé avec des utilisateurs non fiables. Les rapports de mission sont des données transmises à OpenAI en mode cloud : ne pas y placer d'informations personnelles sensibles ou de secrets. Les requêtes Brave doivent être publiques, sans données privées.

V0.1 active : ATLAS (cadrage/décision), ORION, MIDAS, SENTINEL. Les quatre autres rôles sont déclarés mais non exécutés. Délégation fixe et séquentielle ; pas encore d'ordonnanceur général, de RAG, de récompenses automatiques, de production de fichiers ni d'intégrations Gmail/GitHub/Stripe/n8n/Ollama. Aucune vente réelle, aucun envoi d'email, aucun code généré exécuté. Les rapports d'IA ne sont pas des preuves vérifiées. La constitution décrit la cible, non l'état actuel.

Test local : python -m unittest -v test_serveur.py
